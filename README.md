# 🧸 Claw Party

原創線上夾娃娃機網站，可直接部署到 GitHub Pages。

## 功能
- 首頁介紹
- Canvas 夾娃娃遊戲
- Xbox / USB Gamepad API
- 鍵盤控制
- 自訂按鍵
- 手機觸控
- 金幣、分數、最高分、抓取數量
- localStorage 自動保存
- 音效
- 全螢幕
- GitHub Pages / 404 / .nojekyll

## GitHub Pages
1. 建立 GitHub repository。
2. 將本資料夾所有檔案上傳到 repository 根目錄。
3. Settings → Pages。
4. Source 選 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/ (root)`。
6. 儲存後等待 GitHub Pages 建置。

## 手把
瀏覽器支援 Gamepad API 時，Xbox / USB 手把可直接控制：
- 左類比：移動
- A：夾取

不同瀏覽器或手把的按鈕映射可能略有差異。

## 授權
本專案的程式碼與圖形皆為本專案產生的原創範例。你可以修改後部署到自己的 GitHub Pages。
